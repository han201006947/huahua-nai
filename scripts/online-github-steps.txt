花花美甲坊 · 网上扫码（GitHub Pages，比 Netlify 简单）
================================================

【第一次 · 约 10 分钟】

1. 打开 https://github.com 注册账号（邮箱即可，一般比 Netlify 少人机验证）

2. 点右上角 + → New repository
   - 名字填：huahua-nail
   - 选 Public（公开）
   - 不要勾选 Add a README
   - 点 Create repository

3. 在新仓库页点 「uploading an existing file」或 Add file → Upload files
   - 把 dist 文件夹里的【全部文件】拖进去
     （index.html、assets、maoyan、caihui 等，不是拖 dist 文件夹本身）
   - 点 Commit changes

4. 仓库上面点 Settings → 左侧 Pages
   - Source 选 Deploy from a branch
   - Branch 选 main，文件夹选 / (root)
   - 点 Save

5. 等 1～3 分钟，Pages 里会出现网址，形如：
   https://你的用户名.github.io/huahua-nail/

6. 把网址填进项目 deploy.config.json：
   {
     "publicUrl": "https://你的用户名.github.io/huahua-nail/"
   }

7. 在项目文件夹执行：npm run gen-qr
   → 用 release/顾客扫码二维码.png 发微信或打印

【以后更新作品】
  重新 npm run online → 到同一 GitHub 仓库再 Upload files 覆盖上传 → 二维码不用换

【仅店里 WiFi 看】用 npm run out，不必 GitHub
