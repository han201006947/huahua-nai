花花美甲坊 · 网上扫码（GitHub Pages，比 Netlify 简单）
================================================

【第一次 · 约 10 分钟】

1. 打开 https://github.com 注册账号（邮箱即可，一般比 Netlify 少人机验证）

2. 点右上角 + → New repository
   - 名字填：huahua-nail
   - 选 Public（公开）
   - 不要勾选 Add a README
   - 点 Create repository

3. 网页上传 dist 内全部文件（单文件不能超过 25MB，大视频会报错）
   → 若报错 Yowza 25MB：不要网页传了，改用下面「命令行一键上传」

【命令行一键上传 · 含全部视频 · 推荐】

3b. 在项目文件夹打开终端，执行：npm run deploy
   - 提示登录时：用户名 = han201006947
   - 密码 = GitHub Personal Access Token（不是登录密码）
   - 创建 Token：GitHub → Settings → Developer settings → Personal access tokens
     → Generate new token (classic) → 勾选 repo → 生成后复制

4. 仓库 Settings → Pages → Branch 选 gh-pages（不是 main）→ / (root) → Save

5. 等 1～3 分钟，Pages 里会出现网址，形如：
   https://你的用户名.github.io/huahua-nail/

6. 把网址填进项目 deploy.config.json：
   {
     "publicUrl": "https://你的用户名.github.io/huahua-nail/"
   }

7. 在项目文件夹执行：npm run gen-qr
   → 用 release/顾客扫码二维码.png 发微信或打印

【以后更新作品】
  重新 npm run online → 到同一 GitHub 仓库再 Upload files 覆盖上传 → 二维码不用换

【仅店里 WiFi 看】用 npm run out，不必 GitHub
