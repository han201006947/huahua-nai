# 点击播放才加载视频

## 改动背景

顾客打开含视频的款式详情时，若 `<video>` 一开始就带 `src`，浏览器仍可能预取部分 mp4，多个视频款式会更慢。构建侧已做压缩与 poster，前端再改为**只有点击「点击播放」后才挂视频地址**，打开详情几乎只加载轻量封面图。

## 涉及文件

- `src/components/GalleryDetailVideo.vue`（新建）
- `src/components/GallerySection.vue`（详情内改用该组件）

## 行为变化

| 场景 | 之前 | 现在 |
|------|------|------|
| 打开详情 | `preload=none` 但仍带 `src`，可能预取 | 无 `src`，仅显示 poster + 按钮 |
| 点击播放 | 直接 controls | 挂 `src` → `load()` → `play()`，缓冲时提示「正在加载视频…」 |
| 关闭/换款 | — | 重置为未播放状态 |

与 CI 中 `optimize-dist-videos.mjs` 生成的 `.poster.jpg`、720p 压缩 mp4 配合：先看封面秒开，点播放后拉较小文件。

## 验证方式

1. `npm run build` 后本地预览含视频款式。
2. 打开详情：Network 不应出现 `.mp4` 请求。
3. 点「点击播放」：才开始下载 mp4，数秒内可播。
4. deploy 后顾客站强制刷新复测。
