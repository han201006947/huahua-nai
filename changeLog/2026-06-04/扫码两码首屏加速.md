# 顾客/店主两个扫码首屏加速

## 改动背景

用户反馈「顾客扫码二维码」与「店主管理二维码」打开都很慢。店主码 URL 带 `#gallery` 与 `adminLogin`，此前会**立刻挂载整个作品集**；首屏同时拉价目图 preload、最新 3 款封面、GitHub 登录校验，在微信里容易卡 10～30 秒。

## 涉及文件

| 文件 | 变化 |
|------|------|
| `src/App.vue` | 店主/带 `#gallery` 时 idle 再挂作品集，挂上后滚到网格 |
| `src/main.js` | 店主登录校验略延后，先出 Hero |
| `src/components/LatestStylesSection.vue` | 最新 3 款封面 idle 后再请求 |
| `src/components/GalleryAlbumCard.vue` | 封面未加载时显示 shimmer 占位 |
| `src/components/ContactSection.vue` | 微信二维码 `loading="lazy"` |
| `scripts/inject-site-url.mjs` | 预连接 github.io + preload CSS/JS；取消 hb.jpg link-preload |

## 行为变化

| 扫码类型 | 之前 | 现在 |
|----------|------|------|
| 顾客码 | 首屏 Hero + 最新 3 图 + 价目 preload 并发 | 先 CSS/JS + 价目 Hero；最新款略延后出图 |
| 店主码 | 同步挂作品集 + 立刻验 GitHub | 先 Hero，约 0.3～1s 后挂作品集并滚到 `#gallery`，登录校验并行略延后 |

构建后 `hb.jpg` 仍会在 dist 压到约 80KB（需 deploy 后线上生效）。

## 验证方式

1. `npm run build:ci` 后本地 preview，Network：首屏优先 `style.css`、`app.js`，不应立刻大量封面图。
2. deploy 后顾客码：1～3 秒内应看到价目 Hero。
3. 店主码：先见 Hero，随后自动滚到作品集与管理区。
