# 修复店主添加后作品集不显示

## 改动背景 / 需求

用户反馈添加款式后「好像没显示」。排查发现三处问题：

1. 店主预览封面走了 `.thumb` 路径，但 master 分支无缩略图文件 → 封面加载失败
2. 非 dev 环境懒加载未对店主登录放开 → 新卡片可能长期空白
3. 上传后立即 scan GitHub 目录有延迟 → 列表里可能没有新款式

## 涉及文件

- `src/utils/assetUrl.js` — 店主预览用 raw.githubusercontent 原图
- `src/utils/galleryRepoScan.js` — 乐观构建相册 + 扫描重试/回退
- `src/composables/githubGalleryAdmin.js` — 添加后返回完整 albums
- `src/components/GallerySection.vue` — 直接应用 payload；店主封面立即加载；切换 Tab 到对应分类
- `src/components/GalleryAdminPanel.vue` — emit 携带 albums

## 行为变化

添加款式成功后，下方网格立即显示新卡片与封面；并自动切到该款式所属分类 Tab。
