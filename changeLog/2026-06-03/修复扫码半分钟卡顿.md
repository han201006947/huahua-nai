# 修复扫码半分钟卡顿

## 原因

1. **`shouldLoadCover` 误用 `isOnlineAdminMode()`**：线上顾客也被当成「管理态」，**24 张封面同时**从 jsDelivr 拉取，微信里易卡 30 秒。
2. **后台 4.5 秒即拉** master 上整份 `galleryAlbums.js`（raw，国内慢）。
3. 封面走 jsDelivr 跨域，与 app 不同连接，并发差。
4. 顾客首页 **700ms 就挂载作品集**，首屏任务过重。

## 改动

| 项 | 调整 |
|----|------|
| 封面 | 仅「最新款式」+ 进入视口（320px 预加载）才请求 |
| 图片 URL | Pages 站点上用 **同域 `./` 相对路径** |
| 价目 preload | 改为 `./hb.jpg` 同域 |
| 作品集 | 顾客 **滚到下方或点按钮** 再 `import` 挂载 |
| 后台同步 | **15s idle** 后比对 revision；轮询 **30s**；切回前台不强制拉大文件 |
| 去掉 | `onlineListVerified` 首次必拉整表 |

## 验证

1. 顾客扫码：1～3 秒内看到 Hero/价目。
2. 不滚动时几乎无作品集封面请求（Network 面板）。
3. 滚到作品集：可见卡片逐批出图，不应再等半分钟。
