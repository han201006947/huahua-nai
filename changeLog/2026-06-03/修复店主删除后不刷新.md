# 修复店主删除后作品集不实时刷新

## 改动背景 / 需求

用户反馈删除款式后页面没有实时刷新。与「添加」类似：删除后仍依赖 GitHub 目录扫描，API 有延迟且未把返回的 albums 直接写入网格。

## 涉及文件

- `src/utils/galleryRepoScan.js` — `scanAlbumsAfterDelete` / `scanAlbumsAfterDeleteCategory`
- `src/composables/githubGalleryAdmin.js` — 删款/删分类后乐观过滤列表
- `src/components/GallerySection.vue` — 删款后用 payload 立即更新网格
- `src/components/GalleryAdminPanel.vue` — 删分类 emit 携带 albums

## 行为变化

店主删除款式或自建分类后，下方作品集**立即**移除对应卡片，无需等待或手动刷新。
