# 顾客近实时同步与最新款式置顶

## 改动背景 / 需求

店主添加款式后，顾客端更新太慢（此前 30 秒全量拉取）；希望近实时，且新款单独置顶并标注「最新款式」。

## 涉及文件

| 文件 | 变化 |
|------|------|
| `public/gallery-revision.json` | 轻量 revision + latestIds，顾客每 3 秒轮询 |
| `src/utils/githubContents.js` | `fetchGalleryRevision`；抽取 `fetchTextFromRepo` |
| `src/composables/useGalleryAlbums.js` | `tickCustomerGallery` 有变化才拉完整列表 |
| `src/composables/githubGalleryAdmin.js` | 增删时更新 revision 与 latestIds |
| `src/components/GallerySection.vue` | 「最新款式」置顶区块；3 秒轮询 |
| `src/components/GalleryAlbumCard.vue` | 网格卡片复用 |
| `src/components/GalleryAdminPanel.vue` | 添加成功提示文案 |

## 行为变化

- 顾客页每 **3 秒**读 `gallery-revision.json`（约 200 字节）；`rev` 变化才拉 `galleryAlbums.js`。
- 店主 **添加**后：`latestIds` 把新款置顶，顾客约 **3～10 秒**出现在「最新款式」区（带粉色角标）。
- 店主 **删除**后：从 `latestIds` 移除，顾客同样几秒内同步。
- 下方主网格不重复显示已在「最新款式」区的卡片。

## 验证方式

1. 部署后顾客打开作品集，保持页面不关。
2. 店主手机添加一款 → 顾客 3～10 秒内顶部出现「最新款式」。
3. 店主删除 → 顾客几秒内从最新区与主网格消失。
