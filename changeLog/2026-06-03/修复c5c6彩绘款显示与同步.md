# 修复 c5/c6 彩绘款不显示与同步

## 改动背景

用户上传 `caihui/c5`、`caihui/c6` 后 gh-pages 上已有图片，但站点网格/「最新款式」仍空白或不完整。

## 原因

1. `gallery-revision.json` 的 `latestIds` 仅有 `caihui-c6`，**c5 未进「最新款式」**。
2. 封面 **IntersectionObserver 懒加载**，线上网格在视口判定前 `src` 为空，看起来像「没显示」。
3. 为加速扫码，**rev 相同则跳过拉列表**，若打包列表与远程不一致会卡住。
4. 微信内 jsDelivr 偶发失败时，缺少 **GitHub Pages 直链** 回退。

## 改动

| 文件 | 内容 |
|------|------|
| `public/gallery-revision.json` | `latestIds` 增加 c5、c6；rev  bump |
| `src/utils/assetUrl.js` | 新增 `pagesAssetUrl` / `pagesCoverThumbUrl` |
| `src/components/GallerySection.vue` | 线上封面立即加载；多级 @error 回退 |
| `src/composables/useGalleryAlbums.js` | 首次后台同步必拉完整列表 |
| `vite.config.js` | 注入 `__PUBLIC_SITE_URL__` |

## 验证

1. push master 后 Actions 自动 deploy gh-pages。
2. 顾客扫码 → 「最新款式」见 c5、c6；彩绘 Tab 网格有图。
3. 封面 jsDelivr 失败时自动换 Pages 直链。
