# 顾客同步与添加加速

## 改动背景 / 需求

用户反馈：

1. 店主添加款式后图片加载很慢；
2. 店主删除款式后，顾客扫码约 2 分钟仍能看到已删款式。

根因：顾客页此前只读打包进 `app.js` 的静态 `galleryAlbums`，不拉 GitHub 最新列表；店主预览走 raw GitHub 全尺寸原图也偏慢。

## 涉及文件

| 文件 | 变化 |
|------|------|
| `src/utils/githubContents.js` | 新增 `fetchPublicGalleryAlbums()`（无需登录） |
| `src/composables/useGalleryAlbums.js` | 顾客 `refreshCustomerAlbums()` |
| `src/components/GallerySection.vue` | 打开/返回/45s 轮询拉最新列表；增删后刷新 CDN 缓存戳 |
| `src/composables/githubGalleryAdmin.js` | 增删后立即写 `galleryAlbums.js`；上传时用 blob 预览 |
| `src/utils/galleryRepoScan.js` | `buildAlbumFromUpload` 支持 blob；扫描后保留 blob 封面 |
| `src/utils/assetUrl.js` | 店主预览改 jsDelivr master；支持 blob URL |
| `src/components/GalleryAdminPanel.vue` | 选图即生成 blob 预览 |
| `.github/workflows/gallery-sync-deploy.yml` | 监听 `galleryAlbums.js`；checkout 持久凭证 |

## 行为变化

- **店主添加**：上传完成前网格用本地 blob 显示封面，不再等 CDN；预览图走 jsDelivr `@master`。
- **店主删除**：除删 `public/` 外，立即把扫描结果写回 `src/data/galleryAlbums.js`。
- **顾客扫码**：进入页面、从微信返回、每 45 秒（页面可见时）从 raw 拉最新 `galleryAlbums.js`（带时间戳防缓存），删款后约半分钟内同步，无需等 Actions 跑完。

## 验证方式

1. `npm run build` 通过。
2. 部署 gh-pages 后：店主删一款 → 顾客重新打开扫码页或等约 45s → 款式消失。
3. 店主添加 → 上传过程中/完成后网格应立即有图（blob），CDN 就绪后自动切换。
