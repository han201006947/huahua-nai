# 店主添加款式后立即预览

## 改动背景 / 需求

用户问：店主添加后不能直接看到效果吗？原先线上添加款式后要等 GitHub Actions 更新 `galleryAlbums.js` 并 deploy 到 gh-pages（约 1 分钟），店主页面才会出现新款式。

## 涉及文件

- `src/utils/galleryRepoScan.js` — 店主登录后扫描 master 上 `public/` 生成相册列表
- `src/composables/githubGalleryAdmin.js` — 增删后即时 scan，不再 `waitForGallerySync`
- `src/utils/assetUrl.js` — 店主预览时图片走 `@master/public`（上传后立即可见）
- `src/composables/useAdminAuth.js` — 新增 `isOwnerGalleryPreview()`
- `src/components/GallerySection.vue` / `GalleryAdminPanel.vue` — 去掉等待轮询，更新提示文案

## 行为变化

| 角色 | 添加款式后 |
|------|------------|
| **店主**（已登录） | 下方作品集**立即**出现新款式与图片 |
| **顾客**（未登录） | 仍约 1～3 分钟，等 Actions sync + gh-pages deploy |

## 验证方式

1. `npm run deploy` 后手机扫店主二维码
2. 添加款式，上传完成后无需刷新，网格应立刻显示
3. 顾客二维码页约 1 分钟后可见同款
