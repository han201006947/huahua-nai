# 店主顾客同源加速与最新款双显

## 改动背景 / 需求

1. 店主/顾客扫码后加载很慢  
2. 新款应在下方网格正常显示，并在上方「最新款式」重复展示  
3. 店主与顾客内容应一致，仅店主多管理操作；此前店主扫 public 与顾客读 galleryAlbums.js 不同步

## 涉及文件

| 文件 | 变化 |
|------|------|
| `src/composables/useGalleryAlbums.js` | 统一 `tickOnlineGallery`；去掉店主扫 public |
| `src/components/GallerySection.vue` | 首屏不 await 网络；主网格含全部款式；店主/顾客同轮询 |
| `src/App.vue` | 线上立即挂载作品集 |
| `src/utils/githubContents.js` | 读列表不再 ensureSourceBranch |

## 行为变化

- 打开页**立刻**显示打包作品集，后台同步 GitHub（不白屏等网络）
- 店主与顾客均读 `galleryAlbums.js` + `gallery-revision.json`
- 「最新款式」置顶 + 下方分类网格**仍显示同款**（重复可见）

## 验证方式

1. 顾客/店主扫码，首屏 1 秒内应有内容  
2. 店主添加后，双方列表一致；新款在置顶区与下方网格均可见
