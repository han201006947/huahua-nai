# 修复法式最新款与顾客不同步

## 改动背景 / 需求

- 店主扫码添加款式后，「最新款式」置顶区能显示彩绘等新款，但**法式分类新款有时不出现**。
- 顾客扫码页面**长时间仍显示旧列表**，与店主看到的不一致。

## 根因

1. 店主增删成功后，`latestIds` / `rev` 已写入 GitHub，但前端 `onGalleryAdminChanged` **未立即应用** `latestIds`，需等 3 秒轮询才更新置顶区。
2. 管理面板 `emit('changed')` **未携带** `latestIds`、`rev`。
3. 顾客端拉取 `galleryAlbums.js` / `gallery-revision.json` 时 **jsDelivr 优先**，CDN 对 master 常延迟数分钟。
4. 轮询仅在 `rev` 变化时拉完整列表，若 `latestIds` 与列表不同步则置顶 id 找不到对应款式。

## 涉及文件

| 文件 | 变化 |
|------|------|
| `src/composables/githubGalleryAdmin.js` | 增删后返回 `{ latestIds, rev }` |
| `src/composables/useGalleryAlbums.js` | 新增 `patchOnlineGalleryMeta`；轮询检测 `latestIds` 变化与缺失款式 |
| `src/utils/githubContents.js` | 数据文件 **raw 优先**；`fetchPublicGalleryAlbums(rev)` 带缓存破除 |
| `src/components/GallerySection.vue` | 增删回调立即 `patchOnlineGalleryMeta` |
| `src/components/GalleryAdminPanel.vue` | `changed` 事件携带 `latestIds`、`rev` |

## 行为变化

- 店主在任意分类（含法式）添加/删除款式后，**置顶「最新款式」立即更新**，无需等轮询。
- 顾客页每 3 秒轮询 revision，有变化时从 **raw.githubusercontent.com** 拉最新 `galleryAlbums.js`，约 3～10 秒内与 master 一致。

## 验证方式

1. 店主扫码 → 法式分类添加新款 → 顶部「最新款式」**立刻**出现（切到「法式」Tab 亦可见）。
2. 顾客页保持打开 → 3～10 秒内网格与店主一致。
3. 删除款式后，顾客端置顶与网格同步移除。
