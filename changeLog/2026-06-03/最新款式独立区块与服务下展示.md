# 最新款式独立区块（美甲服务下、最多 3 款）

## 需求

- 页面顺序：Hero → 美甲服务 → **最新款式（3 款）** → 作品集
- C5、C6 必须首屏可见（此前藏在 lazy 作品集内，不滚动看不到）

## 改动

- 新增 `LatestStylesSection.vue`：首屏挂载，展示 `latestIds` 最多 3 个
- `useLatestDisplayAlbums.js`：revision 与列表交集；无 revision 时回退列表末尾新款
- `useOnlineGallerySync.js`：后台同步移到最新区块（不必等作品集 lazy load）
- 作品集内移除重复「最新款式」区块
- `latestIds` 上限改为 3；revision 含 c5、c6

## 验证

1. 扫码后滚过美甲服务即可见「最新款式」两列/三列图（含 c5、c6）
2. Hero「最新款式」按钮滚到 `#latest-styles`
3. 点击下方「浏览全部作品集」进入完整网格
