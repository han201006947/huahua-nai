# 仅更新三份 release 文件并加速扫码加载

## 改动背景 / 需求

用户要求只维护 `release/` 下三个文件（不新增其它二维码），并加快扫码到页面可用的时间。

## release 文件（仅此三个）

| 文件 | 说明 |
|------|------|
| `顾客扫码二维码.png` | 【顾客扫码】只看作品集 |
| `店主扫码-管理款式.png` | 【店主扫码】管理款式 |
| `店主管理登录链接.txt` | 店主登录 URL |

生成：`npm run gen-qr` + `npm run gen-admin-qr`

## 加载加速

1. **先挂载页面再验登录**（`main.js`），减少白屏
2. **顾客不再请求 GitHub**，直接用打包静态作品集
3. **店主先 raw 拉 galleryAlbums.js**，后台再扫 public 补全
4. **GitHub 令牌 30 分钟内免重复校验**
5. **扫描 public 时分类/子目录并行请求**
