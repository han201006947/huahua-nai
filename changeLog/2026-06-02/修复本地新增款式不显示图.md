# 修复本地新增款式封面不显示

## 现象

通过「管理款式」新增「手绘彩绘 5」等条目后，网格卡片只有渐变底、没有图片。

## 原因

1. **dev 仍走 jsDelivr**：`vite.config.js` 在开发态也注入了 `__CDN_BASE__`，新图只在本地 `public/`，CDN 上不存在 → 404。
2. **网格请求 .thumb 缩略图**：封面用 `coverThumbUrl` 加载 `*.thumb.jpg/png`，缩略图仅 `npm run build` 时生成，dev 下 public 里没有。

## 改动

- `vite.config.js`：仅 `command === 'build'` 时启用 jsDelivr
- `src/utils/assetUrl.js`：`import.meta.env.DEV` 下封面直接用原图
- `GallerySection.vue`：封面 `@error` 回退原图；去掉重复的 `assetUrl(coverThumbUrl())`
- `gallery-admin-api.mjs`：上传文件名保留中文

## 验证

1. **重启** `npm run dev`（改动了 vite.config）
2. 刷新作品集，「手绘彩绘 5」应显示图片
3. 点开详情也应正常

线上顾客站需 **`npm run deploy`** 后才会看到新款式（本次未 deploy）。
