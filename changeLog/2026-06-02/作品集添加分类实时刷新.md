# 作品集支持添加分类并实时刷新

## 需求

- 除内置彩绘/法式等外，可**新增分类**
- 添加分类后，添加款式时的分类下拉与顶部筛选 Tab **立即更新**

## 实现

- `src/data/galleryCategories.custom.json` 存储自定义分类
- `scripts/gallery-categories.mjs` 合并内置 + 自定义
- `POST /api/gallery/categories` 创建分类并在 `public/catN/` 建目录
- 管理面板左侧「添加分类」、右侧「添加款式」
- `useGalleryAlbums.reloadCategories()` + `onGalleryAdminChanged` 同步 Tab 与下拉

## 使用

1. `npm run dev` → 管理款式 → **添加分类**（名称 + 可选标题前缀）
2. 分类 Tab 与「添加款式」下拉即时出现新分类
3. 选新分类上传图片即可
4. 上线前 `npm run deploy`（需 commit `galleryCategories.custom.json` 与 `public/catN/`）
