# 修复手机添加款式「Branch master not found」与双按钮同时处理中

## 现象

1. 点「添加款式」时「添加分类」按钮也显示「处理中…」（共用 `busy`）
2. 报错 **Branch master not found**（GitHub 仅有 gh-pages，无 master 源码分支）

## 改动

- `GalleryAdminPanel.vue`：分类/款式各自 `busyCategory`、`busyAlbum`
- `githubContents.js`：自动检测/创建 master；GitHub 错误转中文提示
- `package.json`：新增 `npm run push-master`

## 仍需一次（电脑网络正常时）

```bash
git push -u origin master
npm run deploy
```

master 推上去后，手机改款式才能完整 sync 给顾客站。
