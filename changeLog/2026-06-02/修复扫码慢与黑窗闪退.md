# Fix slow load + black window flash: Python threaded server + single start.bat

## 改动背景

用户反馈：双击启动.bat 后扫码半天加载；黑窗口反复闪退弹出。
原因：1) 旧服务单线程，手机同时请求多个文件会卡住；2) 重复双击争用 8765 端口导致窗口闪退；3) 防火墙未放行手机访问。

## 涉及文件

- `scripts/package-resources/serve.py`：Python 多线程本地服务（优先）
- `scripts/package-resources/start.bat`：单窗口启动，优先 py/python，防重复实例
- `scripts/serve-dist.ps1`：无 Python 时的稳定回退 + 已在运行则只开浏览器
- `scripts/package-resources/wifi-once.bat`：增加防火墙放行 8765
- `scripts/package-resources/usage.txt`：补充不要连点、访客 WiFi 说明

## 行为变化

- 有 Python 时加载明显加快，黑窗口只开一个并保持
- 再次双击启动.bat 若服务已在跑，只打开扫码页，不闪退

## 验证方式

1. 管理员运行「允许手机WiFi.bat」
2. 双击「启动.bat」一次，黑窗口保持打开
3. 手机同 WiFi 扫码，首页应在数秒内出现
