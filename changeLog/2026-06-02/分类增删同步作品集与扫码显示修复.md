# 分类增删同步作品集 + 店主扫码后内容显示

## 改动背景

1. 添加/删除分类后，下方筛选 Tab 与作品集网格需立即同步。
2. 店主扫 `release/店主管理登录二维码.png` 登录后，页面应直接看到作品集；此前懒加载导致 `#gallery` 锚点无效，看起来像「内容不显示」。

## 涉及文件

- `src/App.vue` — 扫码或 `#gallery` 时立即挂载作品集区块
- `src/components/GallerySection.vue` — 增删后校正筛选 Tab；登录后滚到作品集
- `src/components/GalleryAdminPanel.vue` — 自建分类删除 UI
- `src/components/AdminLoginPanel.vue` — 精简未登录提示（作品集仍可浏览）
- `scripts/gallery-admin-api.mjs` — `deleteCategory` + `isCustom` 标记
- `scripts/gallery-admin-plugin.mjs` — `DELETE /api/gallery/categories/:key`

## 行为变化

| 操作 | 效果 |
|------|------|
| 添加分类 | 下方 Tab 出现新分类；`emit changed` 刷新网格 |
| 删除自建分类 | 删 `public/catN/`、`galleryCategories.custom.json`、sync 后 Tab/网格同步；内置分类不可删 |
| 删分类时正筛选该分类 | 自动回到「全部」，避免空网格 |
| 店主扫码登录 | 作品集区块立即渲染并滚到 `#gallery` |

## 验证方式

1. `npm run dev` → 未登录可见登录提示 + 下方作品集正常展示
2. `npm run gen-admin-qr` → 微信扫码 → 自动登录并滚到作品集
3. 登录后添加分类 → Tab 即时出现；添加款式后网格刷新
4. 删除自建分类 → Tab 消失、该分类款式从网格移除
