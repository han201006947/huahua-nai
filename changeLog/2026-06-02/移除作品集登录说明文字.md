## 改动背景

页面上「款式管理需店主登录 / npm run dev / gen-admin-qr」等说明不应展示给顾客；店主通过 `release/店主管理登录二维码.png` 扫码即可登录，未登录时与线上一致只浏览作品集。

## 涉及文件

- 删除 `src/components/AdminLoginPanel.vue`

## 行为变化

| 状态 | 页面表现 |
|------|----------|
| 未登录（dev） | 无登录说明框，直接看作品集 |
| 店主扫码登录 | 显示「管理款式（店主已登录）」面板 |
| 生产环境 | 始终无管理入口 |

## 店主登录方式（不变）

1. `npm run dev`
2. `npm run gen-admin-qr` → 扫 `release/店主管理登录二维码.png`
