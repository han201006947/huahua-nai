# 店主扫码登录修复 + 双方实时刷新

## 改动背景

1. 店主扫 `release/店主管理登录二维码.png` 进不去：登录初始化太晚、二维码默认 localhost、Vite 未监听局域网。
2. 店主在手机改款式、电脑预览时，两边需实时同步 Tab 与作品集。

## 涉及文件

- `src/main.js` — 挂载前 `await initAdminAuth()`，扫码参数不丢失
- `src/composables/useAdminAuth.js` — 登录失败弹窗提示；扫码链可重复登录
- `src/composables/useGallerySync.js` — BroadcastChannel 跨标签刷新
- `src/components/GallerySection.vue` / `GalleryAdminPanel.vue` — 增删后广播 + 监听
- `vite.config.js` / `package.json` — `server.host: true`，`npm run dev --host`
- `scripts/generate-admin-login-qr.mjs` — 自动探测局域网 IP 生成二维码

## 店主登录步骤（更新）

1. **重启** `npm run dev`（须重启以应用 host 配置）
2. `npm run gen-admin-qr`（自动用 `http://192.168.x.x:5173`，勿用旧 localhost 二维码）
3. 手机与电脑 **同一 WiFi**，微信扫新生成的 `release/店主管理登录二维码.png`
4. 自动登录并进入作品集，出现「管理款式（店主已登录）」

## 实时刷新

| 场景 | 行为 |
|------|------|
| 本页增删分类/款式/媒体 | 管理面板 + 下方 Tab/网格立即刷新 |
| 手机与电脑各开一个 dev 标签 | 一方改完，另一方自动刷新 |
| 线上顾客站 | 仍须 `npm run deploy` 后更新 |
