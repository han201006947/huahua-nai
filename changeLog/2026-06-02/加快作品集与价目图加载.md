# 加快作品集与价目图加载

## 改动背景

顾客反馈 GitHub Pages 上「价目一览」和作品集封面加载很慢。根因是原图过大（单张最高约 18MB，价目图 2.2MB），手机 4G 下载耗时久。

## 涉及文件

- `scripts/optimize-dist-images.mjs`（新增）
- `package.json`（build 链加入压缩、依赖 sharp）
- `src/components/HeroSection.vue`（fetchpriority / decoding）
- `src/components/GallerySection.vue`（封面视频 preload=none、decoding=async）

## 行为变化

- 每次 `npm run build` 后自动压缩 dist 内大图：价目图宽 1200px，其余作品图宽 960px，JPEG 质量约 78–82
- 17 张大图合计约 **100MB → 约 1.5MB**（视频不变）
- 作品集网格里视频封面不再 preload 整段 mp4，减少无效流量

## 验证方式

1. `npm run build` 日志出现「图片压缩完成」及节省体积
2. `npm run deploy` 后打开 https://han201006947.github.io/huahua-nai/?t=3 强制刷新
3. 首屏价目图、滚动到作品集时封面应明显更快出现
