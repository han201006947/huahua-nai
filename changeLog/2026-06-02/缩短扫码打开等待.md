# 缩短顾客扫码后等待时间

## 改动背景

顾客扫 `release/顾客扫码二维码.png` 后，微信/浏览器都要等较久才看到页面。原因：
1. 加载 JS 前长时间**白屏**
2. 资源仍从 **github.io** 拉取（国内慢）
3. 首屏一次性挂载作品集等重组件

## 涉及文件

- `scripts/fix-dist-html.ps1`（defer 加载 app.js）
- `scripts/inject-site-url.mjs`（首屏占位、jsDelivr、preload 修复）
- `src/App.vue`（延后挂载作品集/关于我们）

## 行为变化

- 扫码后**立刻**显示「花花美甲坊 · 正在打开，请稍候…」（HTML 内嵌，不依赖 JS）
- JS/CSS/价目图走 **jsDelivr**，并 preload 提前下载
- 价目与导航先出来，作品集约 **0.4 秒后再加载**
- **二维码链接不用换**，deploy 后原二维码仍有效

## 验证方式

1. 连 GitHub 后 `npm run deploy`
2. 等 5–10 分钟，微信扫原二维码或打开 `?t=6`
3. 应先看到「正在打开…」，再快速进入价目页
