# 线上手机管理（与顾客同链接）

## 需求

店主不想本地 `npm run dev`，希望像顾客扫码一样打开线上站，用店主二维码或 15235952769 登录后，在手机上增删款式，并同步给顾客视图。

## 实现

| 能力 | 说明 |
|------|------|
| 店主二维码 | 指向 `deploy.config.json` 的 **publicUrl** + 登录参数（与顾客同域名） |
| 登录 | `admin.config.json` 的 **adminSecret 填 GitHub PAT**（repo 读写） |
| 手机管理 | 登录后显示管理面板、删除按钮；通过 GitHub API 写仓库 |
| 顾客同步 | push 后 GitHub Actions 自动 `sync-gallery` + deploy **gh-pages**（约 1 分钟） |
| 本地 dev | 仍可用，逻辑不变 |

## 一次性配置（店主）

1. GitHub → Settings → Developer settings → **Personal access token**（classic 或 fine-grained）
   - 权限：`Contents` 读写 **huahua-nai** 仓库
2. 复制 `admin.config.example.json` → `admin.config.json`
   - `adminPhone`: `15235952769`
   - `adminSecret`: 粘贴 **GitHub 令牌**（勿泄露给顾客）
3. 将 `.github/workflows/gallery-sync-deploy.yml` 推送到 GitHub **master** 分支
4. `npm run build` → `npm run deploy`（部署含管理 UI 的前端）
5. `npm run gen-admin-qr` → 扫 `release/店主管理登录二维码.png`

## 日常使用

- **顾客**：扫 `顾客扫码二维码.png` → 只看作品集
- **店主**：扫 `店主管理登录二维码.png` → 自动登录 → 管理款式
- 改完后约 **1 分钟** 顾客链接刷新即可看到（Actions 自动 deploy）
