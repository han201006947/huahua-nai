# 店主扫码登录才能管理款式

## 需求

管理款式、删除款式、详情内删图/加图，**仅店主 15235952769 扫码登录后可操作**；其他人只能浏览。

## 实现

- `admin.config.json`：店主手机号 + 密钥（已 gitignore）
- 扫码链接带 `?adminLogin=密钥`，登录后 7 天 session
- 写操作 API 校验 `X-Admin-Session` 头
- 未登录：无删除按钮、无管理面板，API 返回 401

## 店主使用

1. 复制 `admin.config.example.json` 为 `admin.config.json`，设置 `adminSecret`
2. `npm run gen-admin-qr` → `release/店主管理登录二维码.png`（链接指向 `http://localhost:5173`，须先 `npm run dev`）
3. 用微信扫该码（本机浏览器亦可直接打开链接）→ 自动登录 → 可管理款式
4. `npm run dev` 本地维护；顾客线上链接不受影响
