# 详情弹层内图片视频增删

## 需求

点开款式详情后，可对**单张图片/单个视频**删除或追加，不仅限于整款删除。

## 实现

- API：`POST/DELETE /api/gallery/albums/:id/media`
- 删除 public 内对应文件并 sync；更新 overrides 的 mediaOrder
- 单文件款式（如 c2.jpg）追加媒体时自动转为文件夹
- 详情弹层（仅 dev）：每项右上角「删除」、底部「+ 添加图片/视频」

## 使用

1. `npm run dev` → 点开某款式详情
2. 每项右上角 **删除**；底部 **+ 添加图片/视频**
3. 删光所有媒体后该款式从列表消失并关闭弹层
