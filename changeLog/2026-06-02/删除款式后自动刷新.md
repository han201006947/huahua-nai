# 删除款式后自动刷新页面

## 需求

删除款式后列表仍显示旧卡片或封面空白，需删除成功后自动刷新。

## 改动

- 删除 API 成功后 `window.location.reload()` 整页刷新
- `sessionStorage` 记住管理面板展开，刷新后仍显示删除按钮
- 增删（添加）仍用热更新：`galleryListKey`、视口内封面立即加载

## 验证

1. `npm run dev` → 展开管理 → 删除一款 → 页面自动刷新，该款消失
2. 刷新后管理面板仍为展开状态
