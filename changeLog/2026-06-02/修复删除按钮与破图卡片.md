# 修复删除按钮消失与破图卡片

## 现象

1. 本地 dev 下卡片右下角「删除」按钮不显示  
2. 「手绘彩绘 5」等卡片破图、标题重复顶在上方  

## 原因

- 删除按钮原先仅在「管理面板展开」时显示，reload 后面板收起  
- 图片 404 时 `alt` 文字显示在卡片顶部，像重复标题  
- `public/caihui/c5` 已不存在但 `galleryAlbums.js` 仍残留条目（orphan）

## 改动

- dev 下删除按钮**常驻**每张卡片右下角，不依赖面板展开  
- 封面 `alt=""`，加载失败显示「暂无图片」占位  
- dev 下封面不再懒加载，避免空白  
- `npm run sync-gallery` 去掉已删的 c5；清理 overrides 中 `caihui-c5`  
- 删款 reload 后自动滚回作品集
