# 作品集本地增删款式（不上线 GitHub）

## 背景

店主需要在电脑上**添加新款式（上传图片/视频）**、**删除旧款式**，但本次**不 deploy 到 GitHub**，仅本地开发可用。

## 实现

| 能力 | 说明 |
|------|------|
| 添加款式 | 选分类 → 上传图片/视频 → 自动在 `public/{分类}/c5/` 等目录建文件夹 → 运行 sync |
| 删除款式 | 下拉选择相册 → 确认 → 删除 `public` 内对应文件夹/文件 → sync |
| 可选标题 | 留空则用「手绘彩绘 N」等自动生成；可勾选「仅看款式」 |
| 线上顾客站 | **无**管理入口；API 仅 `npm run dev` 时存在 |

## 涉及文件

- `scripts/gallery-categories.mjs` — 分类配置共用
- `scripts/gallery-admin-api.mjs` — 增删 + sync 逻辑
- `scripts/gallery-admin-plugin.mjs` — Vite 开发服务器 `/api/gallery/*`
- `src/composables/useGalleryAlbums.js` — 开发态热更新列表
- `src/components/GalleryAdminPanel.vue` — 管理 UI
- `src/components/GallerySection.vue` — 接入面板（仅 DEV）
- `vite.config.js` — 注册插件（`apply: 'serve'`，不打进 build）

## 使用方式

1. 项目目录执行：`npm run dev`
2. 浏览器打开 http://localhost:5173/ ，滚到「作品集」
3. 点 **「管理款式（仅本地）」** 展开面板
4. 添加/删除后页面自动刷新网格
5. 确认无误后再自行执行 **`npm run deploy`** 上传 GitHub（本次未执行 deploy）

## 验证

- `GET http://localhost:5173/api/gallery/albums` 返回 JSON
- `npm run build` 成功，且 `dist/assets/app.js` 不含「管理款式」文案
