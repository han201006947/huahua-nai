# 作品集卡片右下角删除款式

## 需求

删除款式时，在当前分类网格里**每个款式卡片右下角**直接点「删除」，不用在下拉里选。

## 改动

- `GalleryAdminPanel.vue`：去掉「删除款式」下拉区块；`v-model:open` 与父组件同步展开状态
- `GallerySection.vue`：管理面板展开时，每张卡片右下角显示「删除」按钮
- `useGalleryAdminApi.js`：封装 `requestDeleteAlbum`

## 使用

1. `npm run dev` → 作品集 → 点「管理款式（仅本地）」展开
2. 切换分类（彩绘/法式等）查看对应款式
3. 点卡片右下角 **删除** → 确认

## 验证

- 展开管理面板后每张卡有删除按钮；收起后面板按钮消失
- 生产 build 无删除按钮
